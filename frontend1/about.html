ORIGIN STORY

Built from Zero

DataDrop started as a frustration. I kept manually converting pipe-delimited exports at university and thought — this should take one second, not five minutes.

So I built it. Python backend, 9-endpoint REST API, security layer with OWASP headers, rate limiting, and a frontend with 12 custom animations. Total time: three weeks.
